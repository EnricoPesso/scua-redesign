# TSplus Advanced Security (TSplus, França; filial TSplus Brasil)

## O que é (2 linhas)
Caixa de ferramentas de segurança para Windows Server e Área de Trabalho Remota (RDS); inclui "Restrição de Horário de Trabalho" que bloqueia novos logins fora da janela e desconecta a sessão no horário. É segurança de servidor, não gestão de jornada. [1][2][3]

## Features (lista)

**Bloqueio/controle**
- Regra por usuário ou grupo: sempre permitir, sempre bloquear ou permitir só em intervalos por dia, com fuso horário. [2]
- Bloqueia novos logins fora da janela e desconecta a sessão no fim; usa o relógio do servidor para impedir burla por mudar o relógio da estação; entre grupos aplica a combinação mais permissiva. [2][3]
- Aviso agendado na tela antes da desconexão. [2][3]
- Demais recursos de segurança: proteção contra força bruta, geográfica, ransomware, firewall, dispositivos confiáveis, sessões seguras (modo quiosque). [1]

**Painéis e relatórios**
- Painel de segurança e log de eventos; resumos de eventos por e-mail com frequência configurável. [1]

**Alertas**

## O que chama atenção (features incomuns ou inovadoras)
- Aplica o horário com o relógio do servidor para impedir burla por alteração de hora local. [2]
- Alertas de segurança por Microsoft Teams. [1]
- Limitação: serve para sessões em servidor, não para estações Windows comuns (inferência a partir da descrição "Windows Server e Remote Desktop"). [1]
