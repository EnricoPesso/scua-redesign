# Hexnode UEM (Mitsogo Inc., EUA)

## O que é (2 linhas)
Plataforma de gestão unificada de endpoints (UEM/MDM) que oferece controles de "direito à desconexão" por agendamento. O foco principal é celular e tablet; não é um bloqueador de logon de PC. [1]

## Features (lista)

**Bloqueio/controle**
- Android Enterprise: "Work Profile Schedule" pausa o perfil de trabalho no horário (ícones cinza, sem sincronização nem notificações). [1]
- Modo quiosque (Android) e Single App Mode (iOS) em horários definidos; Windows só citado como configuração de apps; macOS não mencionado. [1]
- Automação com lista de bloqueio de apps fora do horário, no fórum do fabricante (Android BYOD); exceção temporária de hora extra por grupo de exclusão com validade de 24 h, citada em outro material do fabricante. [2][3]

**Aprovações**
- Sem fluxo de aprovação; "On-Call Group" alimentado por RH/escala via API documenta acesso fora do horário como intencional. [1]

**Painéis e relatórios**
- Log de auditoria como evidência de quando o acesso foi restringido (exemplo: app de e-mail desativado às 17:01). [1]

**Alertas**
- Não descritos. [1]

**Integrações**
- API com sistemas de RH/escala (on-call). [1]

**Mobile**
- Foco em Android e iOS. [1]

**Conformidade legal**
- Argumentos de direito de desconexão (marketing, legislação não verificada). [1]
